# Pirate Galaxy Forge Core

Inoffizieller 64-Bit-Communityclient für Pirate Galaxy.

**[Windows-Installer herunterladen](https://github.com/FallenIncursio/pirate-galaxy-forge-core-releases/releases/download/v0.2.0-alpha.10/PirateGalaxyForgeCore-0.2.0-alpha.10-Setup.exe)** · **0.2.0-alpha.10** · [Releasehinweise und Prüfsummen](https://github.com/FallenIncursio/pirate-galaxy-forge-core-releases/releases/tag/v0.2.0-alpha.10)

Core enthält die gemeinsame 64-Bit-Technik, allgemeine Korrekturen und begrenzten Komfort. Die ursprüngliche Hilfe bleibt erhalten. Zusätzliche Optionen stehen in der nativen Erweiterung der Spieleinstellungen.

[Core / Enhanced und 32-Bit-Vergleich](FEATURES.md) · [Änderungen dieser Ausgabe](0.2.0-alpha.10.md) · [Installation und Profilübernahme](INSTALLER-UPDATER.md) · [OTB-Diagnose und Dialogfix](ALPHA10-OTB-RESURRECTION.md)

Core und Enhanced sichern den geerbten Wiederbelebungsdialog gegen fehlende oder verspätete Cooldowns ab. Unbekannte Restzeiten erscheinen als Ellipse. Vorhandene Profile, Einstellungen und die alpha.9-Grafikverbesserungen bleiben erhalten.

Enthalten sind modernisierte Bibliotheken, allgemeine Sicherheits- und Ressourcenverbesserungen, der D3D11-HUD-Texturfix, FPS/VSync, HUD-Größe, Chat-Uhrzeit, verschiebbare Komponenten, Ping/FPS unten rechts, Remnant-Filter, Sirius-Bauplanfarben und Kryonitmengen.

Orbitalwarnungen, Bossleisten und weitere Zusatzanzeigen gehören zu **[Forge Enhanced](https://github.com/FallenIncursio/pirate-galaxy-forge-releases)**. Beide Editionen teilen dieselbe Core-Implementierung.

Voraussetzungen: Windows 10/11 x64 und .NET Framework 4.8. Der Starter lädt die geprüfte Spielbasis und Java-Laufzeit bei Bedarf. Core nutzt einen eigenen Datenordner und übernimmt keine Enhanced-Profile automatisch.

50 Editionssuiten, sechs Negativkontrollen, 481 OTB-Prüfungen und je 16 Cooldown-Prüfungen sowie native D3D9-/D3D11-Oberflächentests bestanden. Die Veröffentlichung wurde freigegeben, obwohl derzeit kein OTB-Spieltest mit diesen Änderungen möglich ist. Auch eine reguläre Wiederbelebung mit alpha.10 wurde noch nicht im Spiel bestätigt. Das Widget garantiert weder Belohnung noch Sperrfreiheit; fehlende Daten bedeuten keine bestätigte Inaktivität. [Prüfstand](RELEASE-STATUS-0.2-alpha.10.md).

Updates sind RSA-signiert; der Installer besitzt keine Windows-Authenticode-Signatur. Bibliotheksquellen und Lizenzhinweise gehören zu den Release-Downloads. Forge bleibt eine experimentelle Alpha ohne behauptete offizielle Splitscreen-Freigabe.
